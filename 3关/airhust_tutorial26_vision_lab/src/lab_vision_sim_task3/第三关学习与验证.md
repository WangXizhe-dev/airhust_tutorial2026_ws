1. **任务一：颜色识别**
整体逻辑：先使用 inRange 对图像进行颜色分割，得到二值掩膜，再通过开闭运算清理掩膜，寻找外轮廓，按面积筛选，最后计算最小外接圆，得到目标的中心和半径。

**填空一：去噪**
```python
kernel = np.ones((3, 3), np.uint8)
mask = cv2.morphologyEx(
    mask, cv2.MORPH_OPEN, kernel
)
mask = cv2.morphologyEx(
    mask, cv2.MORPH_CLOSE, kernel
)
```
kernel是结构元素，用来检查像素周围局部区域的小矩阵。
先开运算，再闭运算
目的：先清除零碎的白色干扰，再修补主要目标内部的缺陷。

**填空二：轮廓提取、面积筛选与外接圆**
```python
for contour in contours:  # 逐个处理发现的轮廓
    area = cv2.contourArea(contour)  # 计算轮廓包围的面积

    if area >= min_area:  # 过滤面积过小的目标
        (x, y), radius = cv2.minEnclosingCircle(contour)  # 寻找能够包住整个轮廓的最小圆

        blobs.append(  # 保存圆心、半径和面积
            (round(x), round(y), round(radius), area)
        )
```

**填空三：将每种颜色的结果汇总**

for name, (lower, upper) in COLOR_RANGES.items():  # 遍历红、绿、蓝三种颜色

        print("%s (%d, %d) radius=%d area=%.0f"

**灰色方块和红色小点的去除方法：**
灰色方块不满足三种颜色的 BGR 阈值，在颜色分割阶段就被排除了。红色小点满足红色阈值，通过面积阈值进行过滤。

3. **二维码。** 灰度化之后先试多码接口，把非空字符串和各自的四个角配对保存。没有有效结果才退回单码接口。画四边形验证定位，打印字符串验证解码。这两个结果分别回答“码在哪”和“码里写了什么”。
4. **AprilTag。** 按 25h9 建字典和检测器。25 表示 25 个编码位，h9 表示家族的最小汉明距离为 9。检测器返回 ID 和四个角，四角坐标求平均就是这份练习报告的中心。没有检测时 IDs 可能为空，程序先判断再遍历。
5. **OCR。** 原脚本已经做了灰度读取、放大、轻微模糊和 Otsu 二值化。这次补的是把处理后的图交给 Tesseract，使用英文语言包，`--psm 6` 按一个文本块读取。单独保存预处理图，遇到读错时可以先检查字有没有被阈值切断。
6. **YOLO。** 用课程给的权重做 CPU 推理，置信度阈值 0.25，NMS 的 IoU 阈值 0.45。从每个框取类别编号、类别名、置信度和像素边界。中心取自归一化的 xywh：例如 x 约为 0.522，表示目标中心在图像宽度的 52.2% 处。提高置信度阈值会滤掉较弱的候选框。
