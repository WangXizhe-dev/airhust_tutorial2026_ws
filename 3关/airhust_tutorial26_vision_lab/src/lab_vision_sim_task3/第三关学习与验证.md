## 顺着代码讲

1. **颜色。** OpenCV 读进来是 BGR。对每种颜色单独取阈值得到二值掩膜，再用 3×3 核先开运算后闭运算。按外轮廓算面积，保留至少 500 px² 的轮廓，再取最小外接圆。灰方块在颜色阈值这一步就被排除；红点颜色正确，要靠面积把它筛掉。
2. **二维码。** 灰度化之后先试多码接口，把非空字符串和各自的四个角配对保存。没有有效结果才退回单码接口。画四边形验证定位，打印字符串验证解码。这两个结果分别回答“码在哪”和“码里写了什么”。
3. **AprilTag。** 按 25h9 建字典和检测器。25 表示 25 个编码位，h9 表示家族的最小汉明距离为 9。检测器返回 ID 和四个角，四角坐标求平均就是这份练习报告的中心。没有检测时 IDs 可能为空，程序先判断再遍历。
4. **OCR。** 原脚本已经做了灰度读取、放大、轻微模糊和 Otsu 二值化。这次补的是把处理后的图交给 Tesseract，使用英文语言包，`--psm 6` 按一个文本块读取。单独保存预处理图，遇到读错时可以先检查字有没有被阈值切断。
5. **YOLO。** 用课程给的权重做 CPU 推理，置信度阈值 0.25，NMS 的 IoU 阈值 0.45。从每个框取类别编号、类别名、置信度和像素边界。中心取自归一化的 xywh：例如 x 约为 0.522，表示目标中心在图像宽度的 52.2% 处。提高置信度阈值会滤掉较弱的候选框。

## 实际遇到的问题

Ubuntu 虚拟机一开始无法解析软件源域名，所以在 Windows 上下载与 Linux x86-64、Python 3.8 匹配的离线包，再在虚拟机的独立环境安装。OCR 还需要 Tesseract 引擎和英文语言数据；只有 Python 封装无法识字。YOLO 在这台虚拟机上提示 NNPACK 加速不可用，CPU 推理仍然完成。讲义示例的置信度是 0.74，本次是 0.73，以上表所列实际输出为准。
