# 第一关阶段二的日志

我的修改：
1.rate(1.0)改为rate(20.0)	
因为readme要求维持500ms心跳，原来每秒才发布一次消息，无法满足心跳要求；而现在周期为50ms
2.订阅 /drone改为订阅 /drone/sensor/obstacle_distance	因为必须与传感器发布的话题一致
3.初始目标高度从0改为1.5米
4.结束条件应该是障碍距离 < 0.5 m 之后，而原来是distance < 0.0
5.ros::Time()应改为ros::Time::now()
因为ros::Time() 默认构造一个零时间对象。
而ros::Time::now() 才是获取当前 ROS 时间。
6.publish(fakepoint）改为publish(setpoint)	保证发送的是已经赋值的对象

补充：
在两个 zsh 终端分别进入 `~/airhust_tutorial2026_ws/1关/airhust_tutorial26_ros_basics`。
